COMPARISON OF MERGE SORT AND QUICK SORT

Feature                     Merge Sort          Quick Sort
--------------------------------------------------------------
Duplicate values            Yes                 Yes
Stability                   Stable              Not stable
Stable modification         Not required        Possible
Best-case time              O(n log n)          O(n log n)
Average-case time           O(n log n)          O(n log n)
Worst-case time             O(n log n)          O(n²)
Space complexity            O(n)                O(log n) average
Equal-weight order          Preserved           Not guaranteed
Comparisons for input       16                  16
